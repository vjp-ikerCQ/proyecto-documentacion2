# Despliegue de Infraestructura LAMP con Monitorización

Este repositorio contiene la documentación colaborativa para la planificación, diseño, instalación y mantenimiento de una infraestructura web LAMP con sistemas de monitorización y copias de seguridad automatizadas para una PYME.

El proyecto simula el trabajo del departamento de sistemas de una consultora tecnológica, estructurado bajo un flujo de trabajo profesional en Git con revisión de código y gestión de conflictos.
